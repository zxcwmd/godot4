# AXIOM Launcher

**Современный лаунчер Minecraft для Windows / macOS / Linux — с настоящим движком автоматизации процессов.**

Не Godot-проект: это десктопное приложение на **Electron + React 19 + TypeScript + Vite + Tailwind 4**.
Автоматизация реализована на **mineflayer** — полноценный клиент Minecraft на Node.js: боты честно ходят по миру,
копают, открывают печи и варочные стойки, торгуют с жителями и работают на **любом** сервере без модов.

---

## Возможности

### Лаунчер
- **Менеджер версий** — манифест Mojang, релизы/снапшоты/альфы, поиск, «показать только установленные».
- **Установка клиента** — client.jar, библиотеки, нативные библиотеки, звук/текстуры (assets), с прогрессом по этапам, скоростью и объёмом.
- **Загрузчики** — Fabric, Quilt, Forge, NeoForge. Для Forge/NeoForge автоматически скачивается и запускается официальный инсталлятор.
- **Умная Java** — определяет установленные JDK (JAVA_HOME, PATH, стандартные каталоги), подбирает нужную версию под игру и **сама скачивает Eclipse Temurin**, если подходящей нет.
- **Сборки (инстансы)** — отдельная игровая папка, своё ОЗУ, JVM/игровые аргументы, свой путь к Java, избранное.
- **Моды с Modrinth** — каталог с фильтрами по загрузчику/версии/типу, установка в один клик прямо в папку сборки, включение/отключение (`.disabled`), удаление.
- **Аккаунты** — вход через Microsoft по коду устройства (тот же протокол, что у официального лаунчера) и офлайн-профили с корректным UUID.
- **Консоль** — единая лента логов ядра, установщика, игры и ботов, фильтры, экспорт, запись в `logs/axiom-ДАТА.log`.

### Автоматизация (9 процессов)
| Процесс | Что делает |
|---|---|
| **Автошахта** | Ищет и добывает руду (или камень/дерево/всё подряд), сам выбирает лучший инструмент, добирается через pathfinder, выкидывает мусор при переполнении, считает найденную руду по типам |
| **Автоварка зелий** | Находит варочную стойку, раскладывает бутылочки/ингредиент/топливо, ждёт цикл варки, забирает готовые зелья, поддерживает рецепты: неуклюжее, сила, исцеление, скорость, ночное зрение, огнестойкость, регенерация |
| **Авторыбалка** | Бесконечный цикл `bot.fish()` с перезабросом и подсчётом улова |
| **Автоферма** | Собирает созревшие культуры (пшеница, морковь, картофель, свёкла, тростник, адский нарост) и сажает заново |
| **Автоплавка** | Загружает печь сырьём и топливом, ждёт, забирает результат |
| **Охрана базы** | Атакует враждебных мобов в радиусе, экипирует лучшее оружие, преследует цель |
| **Автоторговля** | Ищет жителей, выбирает подходящую сделку, обменивается пачками |
| **Автосклад** | Складывает добычу в сундуки, оставляя в инвентаре только нужное (список настраивается) |
| **Анти-AFK** | Микродвижения, повороты, взмахи рукой — сервер не кикает за неактивность |

Плюс к этому у каждого бота: **автопереподключение** с backoff, **авто-еда**,
**живая телеметрия** (позиция, измерение, пинг, здоровье, голод, аптайм, пройденное расстояние),
**инвентарь в реальном времени**, **очередь задач** с прогрессом и **лента активности**.

## Быстрый старт

```bash
npm install

# 1) Десктоп-версия в режиме разработки (Vite + Electron с hot-reload)
npm run electron:dev

# 2) Только интерфейс в браузере — демо-ядро с живыми данными (порт 5173)
npm run dev:preview

# 3) Продакшн-сборка и запуск
npm run build && npm start

# 4) Готовые дистрибутивы (AppImage/deb, NSIS/portable, dmg/zip)
npm run dist
```

Требования: Node.js 20+, для самой игры — Java (лаунчер скачает её сам, если нет).

## Архитектура

```
electron/                     главный процесс (Node)
  main.ts                     окно, CSP, жизненный цикл
  preload.ts                  contextBridge: только белый список каналов
  ipc.ts                      все IPC-обработчики, ядро состояния
  services/
    paths.ts                  структура каталогов userData
    store.ts                  атомарный JSON-store
    logger.ts                 кольцевой буфер + файл + шина событий
    mojang.ts                 манифест версий, правила ОС, профили загрузчиков
    installer.ts              скачивание клиента/библиотек/нативов/assets с прогрессом
    java.ts                   определение JDK + авто-загрузка Temurin
    forge.ts                  запуск официального инсталлятора Forge/NeoForge
    launcher.ts               сборка команды запуска, spawn, разбор логов игры
    accounts.ts               офлайн-UUID, вход Microsoft, кэш токенов
    modrinth.ts               поиск/установка/включение модов
  automation/
    index.ts                  BotSession + BotManager (жизненный цикл, очередь, телеметрия)
    tasks.ts                  9 задач автоматизации и их параметры
shared/types.ts               общий контракт main ⇄ renderer
src/                          renderer (React)
  components/                 Shell, Background (аврора + частицы), UI-кит, глобальный поиск
  views/                      Play, Сборки, Версии, Моды, Автоматизация, Аккаунты, Консоль, Настройки
  store/useStore.ts           zustand-стор и подписка на события ядра
  lib/mock.ts                 демо-ядро для веб-превью (полностью повторяет контракт IPC)
```

**Обмен данными:** renderer не имеет доступа к Node. Он вызывает `window.axiom.invoke('axiom:канал', payload)`
и слушает поток событий `AxiomEvent`: `log`, `progress`, `instances`, `accounts`, `bots`, `runtime`,
`launch-state`, `msa-code`, `toast`. В браузере тот же контракт обслуживает демо-ядро — интерфейс не знает, где он работает.

### Автоматизация: как это устроено
- `BotManager` хранит профили (`bots.json`) и создаёт `BotSession` на каждый бот.
- Сессия поднимает mineflayer-клиент, подключает `mineflayer-pathfinder`, подписывается на события
  (spawn, kicked, error, end, death, health, chat) и раз в 1.2 с отдаёт снапшот телеметрии в UI.
- Задачи выполняются **по кругу**: каждая берёт `TaskContext` (логирование, прогресс, отмена, пауза) и
  возвращает управление, когда исчерпала работу в зоне. Пауза/возобновление и остановка — мгновенные.
- Все действия — настоящие: `bot.dig`, `bot.openFurnace/putInput/putFuel/takeOutput`, `bot.openBlock` для
  варочной стойки, `bot.trade` с жителями, `bot.openContainer/deposit`, `bot.attack`, `bot.fish`.

## Файлы приложения

```
<userData>/
  config.json          настройки (акцент, ОЗУ, JVM-аргументы, потоки загрузки)
  instances.json       сборки            accounts.json  аккаунты
  bots.json            профили ботов    logs/          логи по дням
  shared/              общие файлы игры: versions/ libraries/ assets/ runtime/ modloaders/
  instances/<id>/      игровая папка сборки (mods, shaderpacks, saves, config)
```

Аккаунт Microsoft хранит кэш токенов в `<userData>/auth/<ник>`; пароль лаунчер не видит никогда.

## Горячие клавиши
- `Ctrl/Cmd + K` — глобальный поиск (сборки, версии, боты, действия)
- `1…8` — переключение разделов
- `Esc` — закрыть модальное окно

## Юридическое
AXIOM не связан с Mojang Studios и Microsoft. Игра запускается из официальных файлов, для онлайн-серверов нужна лицензия.
Автоматизация (боты) может нарушать правила отдельных серверов — используйте её на своих серверах или там, где это разрешено.
