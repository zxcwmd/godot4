# НУЛЕВОЙ ТАКТ / ZERO BEAT

**Разорви цикл. Заставь машину замолчать.**

Самостоятельный single-player экшен для **Godot 4.3+** на GDScript:
скоростной FPS, боковые 2.5D-секции, три класса и один непрерывный неоновый комплекс.
Внешние модели, плагины и платные ассеты не нужны.

## Запуск

1. Скачай исходники целиком, а не только сцену.
2. В менеджере проектов **Godot 4 → Import** выбери **`project.godot`**.
3. Дождись импорта ресурсов и нажми **F5**.
4. Выбери класс карточкой или клавишами **1 / 2 / 3**. Нажми **«В хаб →»** или **Enter**.
5. Иди вперёд по стрелкам и **прыгни в светящуюся яму**. Внизу начнётся бой.

Проект использует **Compatibility**, без обязательного Vulkan. Рекомендуется
клавиатура и мышь, окно от 1280×800. Боковой режим показывает курсор автоматически;
в первом лице мышь захватывается. **Esc** освобождает мышь и ставит бой на паузу.

## Твоя цель

Ты — последняя живая оболочка внутри машины, бесконечно перезапускающей реальность.
Выход удерживает её Сердце. Чтобы добраться до него:

1. Пройди **шесть боевых коридоров**, чередующих **3D → 2D → 3D → 2D → 3D → 2D**.
2. Вырви **три печати**. Каждая открывается после уничтожения врагов **в обоих
   секторах своего блока**. Подойди к ромбу, чтобы забрать её; здоровье восстановится.
3. В седьмом, трёхмерном секторе уничтожь **Сердце машины**. Перепрыгивай его
   предупреждённые ударные волны и уходи рывком от вееров снарядов.
4. Беги через открывшийся эвакуационный коридор и успей к порталу за **22 секунды**.

Весь комплекс длиной около **540 игровых метров**, хаб, арена, босс и эвакуация
находятся **в одной сцене**, без загрузок между секциями. В боковом режиме мир
остаётся трёхмерным, камера становится ортографической, а движение фиксируется
в плоскости: это **2.5D**, не отдельная спрайтовая игра.

## Оболочки

### 01 — КЛИНОК / мечник

| Оружие | Характер |
|---|---|
| Катана | Быстрые удары; усиленная атака с коротким рывком |
| Парные серпы | Частые широкие взмахи; усиленный круговой удар |
| Рапира | Узкий, длинный и мощный выпад |
| Руки-бензопилы | Очень быстрый контактный урон и дополнительное лечение |
| Коса | Медленный размашистый удар; особая атака притягивает врагов |

### 02 — БАЛЛИСТ / ренжевик

| Оружие | Характер |
|---|---|
| Револьвер | Точный мгновенный выстрел; повышенный урон в голову |
| Метательные диски | Летящие диски с цепочкой рикошетов между целями |
| Рельсотрон | Медленный луч, прошивающий нескольких врагов |
| Дробовик | Россыпь выстрелов; усиленный залп с отдачей |

Боеприпасы бесконечные: ограничители — темп стрельбы и энергия особых атак.

### 03 — АРКАНИСТ / интовик

**1 = огонь, 2 = лёд, 3 = молния.** Каждое нажатие добавляет сферу и вытесняет самую
старую. Нажми **F**, чтобы собрать заклинание из трёх последних сфер. Порядок
не важен: `123`, `312` и `231` дают одно заклинание. До следующего синтеза
подготовленное заклинание сохраняется, даже если ты уже меняешь сферы.

| Сферы → F | Заклинание | Действие |
|---|---|---|
| 111 | Солнечный разрыв | Взрыв и горение |
| 112 | Обжигающий туман | Большая область горения |
| 113 | Метеорный импульс | Тяжёлый взрыв |
| 122 | Ледяной шип | Сильный урон и заморозка |
| 123 | Хаос / схлопывание | Притяжение к точке впереди + ледяной взрыв |
| 133 | Цепная молния | Мгновенный разряд с уроном по соседним целям |
| 222 | Абсолютный ноль | Замораживающая волна вокруг игрока |
| 223 | Гравитационный снег | Притяжение к точке впереди + заморозка |
| 233 | Электрошторм | Электрический взрыв по площади |
| 333 | Громовой копьеброс | Мощный сквозной луч |

**ЛКМ** творит подготовленное заклинание за энергию.
**ПКМ** выпускает дешёвый эфирный разряд и восполняет энергию.
Справочник комбинаций доступен прямо в игре на **Tab**.

## Управление

| Кнопка | Действие |
|---|---|
| WASD / стрелки | Движение в 3D |
| A / D | Движение в боковом режиме |
| Мышь | Обзор в 3D; прицеливание курсором в 2D |
| Пробел, ещё раз в воздухе | Двойной прыжок |
| Shift | Рывок с короткой неуязвимостью |
| ЛКМ / ПКМ | Основная / особая атака |
| Q / E / колесо мыши | Предыдущее / следующее оружие |
| 1 / 2 / 3 в хабе | Смена класса перед прыжком |
| E в хабе | Открыть терминал выбора класса |
| 1 / 2 / 3 в бою за мага | Добавить стихию |
| F | Синтез заклинания |
| Tab | Справочник с паузой |
| Esc | Пауза, звук, чувствительность мыши, снижение тряски |
| M | Включить / выключить музыку |
| R на экране результата | Начать новый цикл |

Используются физические коды клавиш: WASD работает и при русской раскладке.

## Музыка — куда кидать брейккор

**Положи трек в `assets/music/breakcore.ogg`.**

Поддерживаются также `breakcore.mp3` и `breakcore.wav`. После добавления подожди
импорт Godot и перезапусти игру. Приоритет форматов: OGG, MP3, WAV.
Подробности петли и экспорта — в [assets/music/README.md](assets/music/README.md).

Без твоего файла играет **оригинальный процедурный брейкбит на 186 BPM**:
синтезированные ударные, дробления и бас. Это встроенный музыкальный эскиз,
а не готовый профессионально сведённый брейккор-трек. Звуки выстрелов, попаданий,
рывков и разрушений тоже генерируются кодом. Для публикации используй музыку,
на которую у тебя есть разрешение.

## Темп, рейтинг и выживание

- Каждое убийство возвращает **7 HP и 6 энергии**. Бензопилы лечат ещё и при контакте.
- Серия убийств повышает рейтинг **C → B → A → S → SS → SSS**.
- Смена оружия или заклинания даёт больше комбо. Урон по игроку и промедление
  снижают серию. Не стой на месте.
- Рывок восстанавливается за **0,85 с**, даёт краткую неуязвимость и сохраняет темп.
- Рывок не телепортирует сквозь стены. Снаряды, лучи и удары учитывают препятствия.
- Здоровье ближайшей цели и подсказка «цель позади» помогают дочистить блок.
- Личный рекорд хранится локально в `user://zero_beat.cfg`.
- Смерть начинает новый забег через хаб: сохранений посреди уровня нет.

В **Esc** есть настройка «Меньше тряски и вспышек». Игра всё равно содержит яркие
неоновые контрасты и быстрые эффекты; режим не является медицинской гарантией
безопасности при фоточувствительности.

## Что лежит в проекте

```text
project.godot            точка входа для Godot
scenes/main.tscn         единственная основная сцена
scripts/main.gd         состояние забега, волны, печати, урон, победа
scripts/world.gd        процедурный комплекс, хаб, двери, эвакуация
scripts/player.gd       движение, перспектива, оружие, стихии
scripts/enemy.gd        рывковые враги, стрелки, тяжёлые враги, босс
scripts/projectile.gd   снаряды с проверкой пути между кадрами
scripts/hud.gd          русские меню, HUD, настройки, справочник
scripts/fx.gd           частицы, трассеры, кольцевые волны
scripts/audio.gd        импорт трека, синтез фонового ритма и SFX
scripts/forge.gd        общая фабрика геометрии и материалов
assets/music/           твой трек
assets/FONT-LICENSE.txt лицензия встроенного DejaVu Sans Bold
```

Это **играбельный процедурный прототип**, а не обещание AAA-графики: окружение,
персонажи и оружие собраны из геометрии; нет сторонних анимационных пакетов,
сетевой игры или отдельного спрайтового рендера. Всё основное поведение открыто
в коротких самостоятельных модулях и готово для замены визуальных ассетов.

## Проверки

При установленном Godot 4 можно прогнать импорт и интеграционный smoke-тест:

```bash
GODOT=/путь/к/Godot ./tests/run.sh
```

Или вручную на любой платформе:

```text
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/smoke.gd
```

Тест создаёт настоящую сцену и проверяет выбор классов, падение в яму,
вызов оружия/заклинаний, урон и неуязвимость, физический hitscan, смену перспективы,
запертые и открытые печати, босса, эвакуацию и проигрыш. Графику, звук и баланс
нужно дополнительно проверять обычным запуском **F5**.
