RIFT RUSH 0.3.1 — ЗАПУСК НА WINDOWS

1. Закрой Godot. Не запускай project.godot прямо из окна ZIP-архива.
2. Распакуй ВЕСЬ архив в НОВУЮ папку, например:
   %LOCALAPPDATA%\RiftRush-0.3.1
   Этот путь можно вставить в адресную строку Проводника.
   Не распаковывай поверх старой копии и не используй Program Files/OneDrive.
3. В папке с project.godot обязательно должны быть:
   scenes\main.tscn
   scripts\game.gd
   остальные папки scripts, shaders, assets и tools.
   GitHub ZIP содержит дополнительную внешнюю папку — открой её.
4. Дважды нажми CHECK_PROJECT.cmd. Python и права администратора не нужны.
   MISSING — файл отсутствует.
   CHANGED — файл отличается от выпуска (в том числе при твоём редактировании).
   UNREADABLE — файл нельзя прочитать.
   WRITE / REPLACE FAILED — нельзя создать/заменить временный файл в папке.
   Проверка НЕ исправляет и НЕ перезаписывает твои игровые файлы.
5. В менеджере проектов Godot выбери «Импортировать» и укажи project.godot
   именно из НОВОЙ папки. Не запускай старую запись из списка проектов.
6. Дождись импорта, нажми F5. Рекомендуется официальный Godot 4.4+.

Если CHECK_PROJECT.cmd показывает PASS, но Godot пишет Safe save failed:
- путь проекта в редакторе должен совпадать с путём, который напечатала проверка;
- проверь журнал защиты Windows: может быть заблокирован именно Godot.exe;
- при подтверждённой блокировке можно разрешить доверенный официальный Godot
  точечно. Не отключай антивирус целиком и не выключай Safe Save;
- проверка не может проверить папку настроек редактора Godot: Safe save failed
  может относиться и к ней, а не к самому проекту;
- пришли строки ошибки и результат CHECK_PROJECT.cmd — это поможет отличить
  проблему доступа от неполной распаковки.

Сцена должна находиться по пути:
  <папка с project.godot>\scenes\main.tscn
А не рядом с ZIP, не внутри двойной вложенности scenes\scenes и не main.tscn.txt.

Не удаляй исходники и сохранения. Новая распаковка не требует отключать защиту.
