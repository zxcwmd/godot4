# Твой брейккор — сюда

Положи **один** трек в эту папку и назови его:

- **`breakcore.ogg`** — рекомендуемый вариант (Ogg Vorbis);
- или `breakcore.mp3`;
- или `breakcore.wav`.

Полный путь: **`res://assets/music/breakcore.ogg`**.

Godot импортирует файл автоматически. Перезапусти игру — трек подхватится вместо
встроенного ритма. Если есть несколько форматов, приоритет: OGG → MP3 → WAV.
Трек повторяется после завершения. Для бесшовного зацикливания включи **Loop** в
панели Import и нажми **Reimport** (для WAV укажи границы петли).

Рекомендуемый характер: 175–210 BPM, резаные брейки, плотный бас, контрастные паузы.
Встроенный оригинальный синтезированный ритм — **186 BPM**, не коммерческий трек.
Индикатор пульсации использует этот темп: он не анализирует BPM импортированной песни.

**M** выключает только музыку. В **Esc → Музыка** есть регулятор громкости.
Шина `Music` отделена от `SFX` в `default_bus_layout.tres`.

Используй трек, на который у тебя есть права. Музыкальные файлы исключены из Git
через `.gitignore`, чтобы случайно не отправить чужой трек в публичный репозиторий.
Это не мешает локальному импорту и экспорту игры. Для распространения исходников
с разрешённой музыкой добавь её отдельно или осознанно используй `git add -f`.
