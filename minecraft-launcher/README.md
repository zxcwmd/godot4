# Aurora Launcher

Современный лаунчер Minecraft с «живым» интерфейсом (стекло, градиенты, шейдерный фон)
и встроенным **пультом автоматизации**: автошахта, автоварка зелий, авторыбалка,
автоферма, автоплавильня, автопитание, анти-AFK и пользовательские макросы.

Проект написан на **Godot 4 (GDScript)** — интерфейс собирается из кода, поэтому
лаунчер не зависит от внешних ассетов и шрифтов: все иконки рисуются векторно,
фон и панели — шейдерами `canvas_item`.

---

## Что умеет

### Лаунчер
* Манифест версий Mojang: релизы, снапшоты, беты и альфы.
* Полная подготовка запуска: клиентский jar, библиотеки (с разбором `rules` по ОС и
  архитектуре), нативные библиотеки LWJGL, индекс ресурсов и объекты ассетов,
  поддержка `legacy`-ассетов для очень старых версий.
* Загрузчики модов: **Vanilla, Fabric, Quilt, Forge, NeoForge** — ставятся автоматически
  при первом запуске (Fabric/Quilt через profile-json, Forge/NeoForge через installer-jar).
* Java: поиск системных JRE, автоскачивание Temurin JRE нужной мажорной версии,
  распаковка собственным ZIP-ридером (без внешних зависимостей).
* Аккаунты: оффлайн-режим (UUID из ника) и полноценный вход через **Microsoft**
  (device-code flow → Xbox Live → XSTS → Minecraft Services).
* Авто-бэкап сохранений перед каждым запуском.
* Каталог модов **Modrinth**: поиск с фильтрами по версии и загрузчику, установка,
  удаление и проверка обновлений.
* Свой читатель ZIP: нужен и для JRE-архивов, и для `.mrpack`-модпаков.

### Автоматизация
* 8 видов ботов, схема параметров описывается данными — новый вид бота не требует
  правок в интерфейсе.
* Триггеры: вручную, при запуске игры, по расписанию (интервал).
* Ограничение числа одновременных ботов, повторные запуски, живой статус, счётчик
  действий, оценка прогресса по времени.
* Лаунчер генерирует для каждой задачи отдельный Node.js-проект (`bot.js`,
  `package.json`, обёрточные скрипты), сам ставит зависимости через `npm install`
  и запускает бота; статус и прогресс читаются из `state.json`, вывод — из `out.log`.
* Живой журнал с фильтрами (все / боты / лаунчер и игра / ошибки).

### Оформление
* Шейдерный фон «аврора»: fbm-шум, светящиеся ленты, звёзды, виньетка.
* Стеклянные панели с градиентной заливкой, тонкой обводкой и внешним свечением.
* Векторные иконки (28 штук), круговые индикаторы, кастомные слайдеры, тумблеры,
  выпадающие списки с поиском, тосты, плавные переходы между страницами.
* Четыре акцентных цвета, регулировка яркости фона, режим «меньше анимаций».

## Запуск

1. Откройте папку `minecraft-launcher/` в Godot 4.2 или новее.
2. Нажмите **F5** (главная сцена — `scenes/main.tscn`).
3. На странице «Экземпляры» нажмите **Новый экземпляр**, выберите версию и загрузчик.
4. Нажмите **Играть** — лаунчер сам скачает клиент, библиотеки, ресурсы и Java.

Экспорт: `File → Export` (пресеты не добавлены, метод рендеринга — GL Compatibility,
чтобы шейдеры работали на любом оборудовании).

## Структура

```
minecraft-launcher/
├── project.godot              автозагрузчики (Bus, Net, Store, Notify, Java, Mojang, ...)
├── scenes/main.tscn           единственная сцена: точка сборки интерфейса
├── icon.svg
└── scripts/
    ├── core/
    │   ├── bus.gd             шина сигналов «ядро ↔ интерфейс»
    │   ├── net.gd             HTTPRequest: JSON и скачивание с прогрессом
    │   ├── store.gd           настройки, экземпляры, задачи, аккаунт (user://aurora)
    │   ├── notify.gd          очередь уведомлений
    │   ├── constants.gd       endpoint-ы, пути, палитра, человекочитаемые названия
    │   ├── util/zip.gd        минимальный читатель ZIP (deflate)
    │   ├── util/proc.gd       поиск исполняемых файлов, запуск и остановка процессов
    │   ├── services/
    │   │   ├── mojang.gd      манифест версий и version.json
    │   │   ├── java_runtime.gd   поиск и установка Java (Temurin)
    │   │   ├── loader_service.gd Fabric / Quilt / Forge / NeoForge
    │   │   ├── game_launcher.gd подготовка и запуск игры, чтение игрового лога
    │   │   ├── modrinth.gd    каталог модов и модпаков
    │   │   └── msauth.gd      вход через Microsoft
    │   └── automation/
    │       ├── automation_schema.gd  описание параметров каждого вида бота
    │       ├── bot_templates.gd      шаблоны ботов на Mineflayer
    │       ├── node_runtime.gd       npm install, запуск, чтение состояния
    │       └── automation_service.gd планировщик, очередь, статусы
    └── ui/
        ├── main.gd            сборка окна, связь с ядром
        ├── shell.gd           боковое меню, верхняя панель, переключение страниц
        ├── launcher_page.gd   базовый класс страницы
        ├── kit.gd             помощники вёрстки (панели, строки, плитки)
        ├── theme.gd           тема, стили, градиентные текстуры
        ├── background.gd      шейдерный фон
        ├── widgets/           шейдерные поверхности, кнопки, иконки, слайдеры, консоль...
        └── pages/             home, instances, automation, mods, settings
```

Данные лаунчера (сборки, моды, боты, бэкапы) хранятся в `user://aurora/`
(`OS.get_user_data_dir()/aurora`), путь показывается в настройках.

## Как работает автоматизация

1. Вы создаёте задачу: вид бота + параметры + триггер.
2. Лаунчер подставляет конфигурацию в шаблон Mineflayer-скрипта и пишет проект в
   `user://aurora/automation/<id>/`.
3. При первом запуске в фоне выполняется `npm install` (интерфейс не подвисает).
4. Бот запускается отдельным процессом; лаунчер раз в секунду читает `state.json`
   (состояние, число действий, примечание) и `out.log`, обновляет интерфейс и журнал.
5. По завершении (или по кнопке «Остановить») процесс корректно гасится через `SIGTERM`.

Виды ботов: `mine`, `brew`, `fish`, `farm`, `smelt`, `eat`, `afk`, `macro`
(свой сценарий: `chat`, `wait`, `key`, `dig`, `use`, `look`, `jump`, `swing`, `eat`).

> **Важно.** Автоматизация действий в игре допустима только там, где это разрешено:
> в одиночной игре, на своём сервере или там, где правила сервера это допускают.
> За нарушение правил сервера ответственность несёт пользователь.

## Дизайн-превью

`preview/index.html` — статическая HTML-копия интерфейса (тот же визуальный язык),
чтобы оценить оформление без запуска Godot. Откройте файл в браузере или поднимите
любой статический сервер:

```bash
cd minecraft-launcher/preview && python3 -m http.server 8080
```
